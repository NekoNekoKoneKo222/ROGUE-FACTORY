# ROGUE FACTORY — Infinite Industrial World

**永久工場 × 自動化 × 効率化 × タワーディフェンス × 戦車工業**

ROGUE FACTORYのメインゲームは、ステージを周回するモードから、ひとつの広大な永続ワールドで工場を拡張し続ける「工業サバイバル」に変更しました。Factorioのように資源を運び、加工し、電力と物流のボトルネックを解消しながら、増える敵の襲撃に備えます。

**公開URL:** https://rogue-factory.onrender.com/

## 新しいメインの遊び方

1. ホームの「無限工業ワールドを始める」を選び、初回はNeonに永久基地を作成します。
2. マップ上で資源鉱脈を探します。鉄・銅・石炭・石・原油の分布は座標とワールドシードによって決まり、32×32タイル単位のチャンクとして無限に生成できます。
3. 鉱脈上に採掘機を置き、コンベア→電気炉→コンベア→組立機とつなぎます。素材は設備の中を実際に1タイルずつ移動します。
4. 組立機で弾薬、歯車、電子回路、研究パック等を作り、研究所で研究ポイントを蓄積します。
5. 研究で分配器、高度な自動化、石油化学、太陽光、レーザー、戦車工業などを解放します。
6. 電柱・発電機・蓄電池を適切に配置。電力不足では一部設備が停止し、生産効率が低下します。
7. 土地開拓で建設半径を12タイルずつ広げます。固定ステージの終わりはありません。
8. 工場の汚染に呼ばれて敵機械が襲来します。弾薬を消費する砲塔、レーザー、壁、修理ロボットで本拠地を守ります。
9. 戦車工場で戦車を製造し、資源バンカーに搬送して兵器庫へ納品。研究を終えた戦車はマップ上へ防衛出撃し、実際に移動・射撃します。

### 工場操作

- **建設**：画面左から設備を選び、ワールドの空きマスをクリック/タップ
- **画面移動**：ワールド上をドラッグ/スワイプ
- **拡大縮小**：マウスホイール、画面の＋/−ボタン
- **回転**：Rキー（設置方向）または設備を右クリック/「回転」モード
- **撤去/修理/強化**：設備を調査し、右側の詳細パネルから操作
- **レシピ変更**：組立機や戦車工場を選んで製造レシピを選択
- **まとめて敷設**：「ライン」モードに切り替えてドラッグ、または2地点を順にタップ。ベルト・パイプ・壁・電柱を一括敷設
- **生産効率を見る**：工場状況パネルに採掘・製造・出荷の毎分速度、電力供給と消費、蓄電量を表示

## 実装している工業設備

| 系統 | 現在の設備 |
| --- | --- |
| 資源 | 採掘機、石油ポンプ |
| 物流 | コンベア、分配器、インサーター、チェスト、資源バンカー |
| 製造 | 電気炉、組立機、製油所、化学プラント、戦車工場 |
| エネルギー | 石炭火力発電、電柱、ソーラーパネル、蓄電池 |
| 研究 | 研究所、研究ツリー、設備レベルと製造速度 |
| 防衛 | 機関砲塔、レーザー砲、防壁、修理ロボット、出撃戦車 |
| 開拓 | レーダー、領土拡張、中央コア |

**物流上のルール:** 資源は隣接する設備へ向きに沿って流れます。完成品を「資源バンカー」へ運ぶとワールド共通倉庫に入ります。離れた設備に瞬間転送されるわけではありません。電柱の接続範囲によって発電ネットワークが分かれます。

## 基地とオンラインPvP

- **Neon PostgreSQL** の既存 home_accounts.base JSONB に、工業ワールドの永続データを新規プロパティとして追加保存します。
- 既存12×12基地・戦車兵庫・戦報データは削除せず保持します。旧基地・模擬1vs1・非同期のプレイヤー襲撃はサブモードです。
- 他プレイヤーからの非同期襲撃では、新しい工業ワールドの砲台・レーザー・防壁・自動戦車が防衛力として反映されます。工業ワールドで製造して資源バンカーに納品した戦車も襲撃に使用できます。襲撃で一部の設備が損傷する場合はありますが、**建設物は削除されません**。修理して復旧できます。
- 工場の生産・敵機械のAI・資源消費・製造はサーバーで判定し、ブラウザはレンダリングと操作を担当します。
- サイトに接続している間は一定間隔でワールドを更新。離席・ログアウト時は敵の攻撃を停止し、オフライン資源生産のみ一部を簡易計算します（最大8時間分）。設備は消えません。
- 既存の秘密トークン方式を維持しているため、ブラウザのサイトデータを消すとアカウントを復旧できない可能性があります。トークンを他者へ渡さないでください。

## 開発版の制限 / 今後の開発

今回の実装は **Factorioレベルのゲームを目指すための動く基盤** です。Factorioそのものと同水準の完成度・規模を達成したという意味ではありません。

以下は未実装または初期実装です。

- 敵AIは簡易な接近戦で、敵拠点の破壊、詳細な経路探索・地形回避は今後
- 鉄道・機関車・列車信号・回路ネットワーク・ベルトの多レーン化・高度なロボット物流・青写真の保存/共有は今後
- 敷地は資源を消費して際限なく拡張できる設計ですが、**同時配置設備数には初期アルファの安全上限1600基**があります。さらに大規模な自動工場を動かすには、チャンク単位の個別保存、近距離だけのシミュレーション、サーバー負荷最適化が必要です
- 兵器・工業のバランス調整、大規模マルチワールド、詳細な電力・液体物理は段階的に拡張
- 襲撃PvPはサブ機能として旧形式の戦力比較で残ります。戦車による他プレイヤー拠点へのリアルタイム進軍はまだありません
- 工場世界のデータはNeonで保存されますが、ランクや外部認証はまだありません

## ローカル起動

Node.js 20以降、PostgreSQLを用意してください。

    npm install
    npm test
    npm start

http://localhost:3000 で開きます。恒久ワールドにはDATABASE_URLが必要です。Render環境には既存の専用Neonプロジェクトの接続URLが設定されています。

主な構成：

    game/industrial-world.js        工業・電力・流体・研究・生産・敵・戦車サーバー処理
    public/industrial-shared.js    無限地形と鉱脈の共有決定関数
    public/industrial.js           無限ワールドCanvasマップ、操作、工場分析UI
    public/industrial.css          工業UIレイアウト
    game/headquarters.js           既存の恒久基地、戦車兵庫、PvP襲撃
    server.js                      WebSocket/Neon認証・データ保存・シミュレーション
    tests/industrial-world.test.js 工業ワールドの自動テスト
