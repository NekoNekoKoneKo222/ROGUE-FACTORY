# ROGUE FACTORY

工業 × 永続基地 × 戦車生産 × 広大なワールドマップ × 工場防衛

メインは自分の工場を何日も育成し、戦車や自走砲を生産して世界のステージを攻略するゲームです。PvPは他プレイヤーが常設基地へ襲撃してくるサブ要素です。基地そのものは消滅しません。

## ゲームの主な機能

- **永続本拠地**：12×12マスで発電機・採掘機・コンベア・精錬機・弾薬製造・砲台・装甲・戦車工場を建設。設備回転、アップグレード、解体、修理も可能
- **自動生産**：鉱脈から掘り出し、ベルトで精錬機・弾薬工場へ搬送する接続を判定し、時間経過で資源を生成。ログアウト中も最大12時間分を計算
- **兵器生産**：戦車工場で主力戦車を生産。戦車工場Lv.2で自走砲を解放。製造予約が完了したら兵器庫へ追加
- **巨大ワールド**：5地域、24ミッション、3500×1250のスクロールマップ、ボス・寄り道・星評価・実績・マスタリー・設計図コレクション
- **PvE防衛**：波状に襲来する敵機械軍を砲台やミサイル、基地の駐屯戦車で防衛。最初のチュートリアルは実際に生産ラインを組む
- **別プレイヤーからの襲撃**：他のオンライン登録基地を探し、戦車1〜20台の戦力を投入。サーバー側で戦力比較、戦報を保存。防衛側はログアウト中でも攻撃を受ける場合がある。基地と設備は削除されず、少量の資源と基地HPが減少。防衛側へ15分シールド付与
- **オプションの模擬PvP**：従来の1vs1もサブモードとして維持。3分の建設フェーズの後、工場同士の戦闘を開始
- **演出**：火花、発電の放電、ミサイル軌跡、爆発、工場の稼働アニメーション、襲撃レーダー。HIGH/LOW/OFF設定

## ゲームの始め方

1. https://rogue-factory.onrender.com/ を開き、名前を決めて「恒久基地を開く」を選択。
2. 鉱脈の上に採掘機、そこからコンベア・精錬機・弾薬工場をつなぐ。
3. スクラップを集めて戦車工場を建て、主力戦車や自走砲を製造する。
4. 広大なワールドマップに出撃して防衛ミッションをクリアし、地域を解放する。
5. 他プレイヤーが登録済みなら「襲撃」タブから攻撃する。襲撃された記録は「戦報」で確認可能。

## 保存方法と制限

- 恒久基地・資源・兵器・他プレイヤーの襲撃履歴はゲーム専用のNeon PostgreSQLに保存。
- アカウント復帰用の秘密トークンは現在ブラウザのlocalStorageで保管。別端末でのログインやメールによる復旧は未実装。ブラウザのサイトデータを削除すると基地への再アクセスができなくなる場合があります。秘密トークンは共有しないでください。
- 星評価・コレクション・マスタリーは初期版ではブラウザ保存で、DB同期はまだありません。
- 防衛ミッション中の工場は本拠地のスナップショットです。戦闘中に設置した設備はそのミッション専用で、恒久本拠地の配置はホーム画面で編集してください。
- 戦車の襲撃は初期版ではサーバーが攻撃・防衛値を比較する方式で、リアルタイム戦車の経路探索・直接操縦はまだありません。

## 開発・起動

Node.js 20以上。

    npm install
    npm test
    npm start

ローカルURLは http://localhost:3000 です。恒久基地の保存にはDATABASE_URLが必要です。設定されていない場合はCPU模擬戦を遊べますが、本拠地と他プレイヤー襲撃は利用できません。

DBマイグレーションは npm run db:migrate を実行します。SQLは sql/001_initial.sql と sql/002_headquarters.sql にあります。RenderへのデプロイはGitHubのmainブランチから自動です。

ソースの主要箇所: game/headquarters.js は基地/戦車/襲撃、game/engine.js は工場/ウェーブ防衛、public/hq.js は基地UI、public/world.js はワールドマップ、server.js はWebSocketサーバー。
